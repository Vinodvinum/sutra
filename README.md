## 📋 Overview

**Sutra** is a dashboard-style application designed as a life operating system (Life OS) — a personal productivity and management tool that helps users organize, track, and optimize day-to-day workflows. Built with a modern TypeScript-based web stack and deployed on Vercel.

This is an **ongoing project** in active development.

---

## ✨ Features

- 📊 Dashboard UI for life and task management
- 🗓️ Habit, goal, and progress tracking
- 🤖 AI-assisted suggestions and automation hooks
- 📡 Real-time data sync with Firebase / Supabase
- 🌐 Deployed on Vercel with public dashboard route
- 🔄 Modular architecture for iterative expansion
